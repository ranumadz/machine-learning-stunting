
# Stunting Prediction Using Machine Learning

This project analyzes stunting data of children aged 12 to 59 months using machine learning algorithms. It is built to assist public health services in predicting and monitoring child stunting in Tangerang, Indonesia.

## Features
- Data preprocessing (cleaning, transformation)
- Machine learning models: Linear Regression, Naive Bayes, and Neural Network
- Model evaluation and comparison
- Simple Streamlit web application for predictions
- Visualizations and classification summaries

## Tech Stack
- Python
- Pandas, NumPy, Scikit-learn, TensorFlow/Keras
- Matplotlib, Seaborn
- Streamlit

## Folder Structure
```
├── data/               # Dataset files (train/test)
├── notebooks/          # Jupyter notebooks for exploration and modeling
├── app/                # Streamlit app code
├── models/             # Saved models (e.g., .pkl or .h5)
└── README.md           # Project documentation
```

## Use Case
Helps healthcare professionals in early identification of potential stunting cases based on weight, height, and age data.
